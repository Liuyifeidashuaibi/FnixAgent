## 二、架构 / Architecture

### 前端 (React)

用 [`react-i18next`](https://react.i18next.com/) + `i18next`:

```typescript
// apps/workbench/src/i18n/index.ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import en from './locales/en-US.json'
import zhCN from './locales/zh-CN.json'
import zhTW from './locales/zh-TW.json'

await i18n.use(initReactI18next).init({
  resources: {
    'en-US': { translation: en },
    'zh-CN': { translation: zhCN },
    'zh-TW': { translation: zhTW },
  },
  lng: detectBrowserLang(),
  fallbackLng: 'en-US',
  interpolation: { escapeValue: false },
})
```

### Python 后端

用 [`gettext`](https://docs.python.org/3/library/gettext.html) (i18n) +
[`babel`](https://babel.pypa.io/) 提取:

```python
# src/fnixagent/i18n.py
import gettext
import os

_DOMAIN = "fnixagent"
_LOCALES_DIR = os.path.join(os.path.dirname(__file__), "locales")

def _(message: str) -> str:
    lang = os.environ.get("FNIX_LANG", "zh-CN")
    t = gettext.translation(_DOMAIN, _LOCALES_DIR, languages=[lang], fallback=True)
    return t.gettext(message)

# 用法
print(_("Hello, world"))
```

### Skill Prompt

Skill 默认是英文,但支持多语言版本:

```
~/.fnix/skills/code-review/
├── SKILL.md           # 英文(默认)
├── SKILL.zh-CN.md     # 简体中文版
└── SKILL.ja-JP.md     # 日文版
```

加载时根据用户语言 fallback:

```python
def load_skill(name: str, lang: str) -> Skill:
    for candidate in [lang, lang.split("-")[0], "en-US"]:
        path = SKILLS_DIR / name / f"SKILL.{candidate}.md"
        if path.exists():
            return parse_skill(path.read_text())
    # fallback
    return parse_skill((SKILLS_DIR / name / "SKILL.md").read_text())
```

## 三、字符串规范 / String Conventions

### 1. 不要硬编码

```tsx
// ❌ 错误
<button>提交</button>
toast.success("保存成功")

// ✅ 正确
<button>{t('submit')}</button>
toast.success(t('save.success'))
```

### 2. 复数

```json
// en-US.json
{
  "messages": "{count, plural, =0 {No messages} one {1 message} other {# messages}}"
}
```

```json
// zh-CN.json(中文无复数)
{
  "messages": "{count} 条消息"
}
```

```typescript
t('messages', { count: 5 })
// en: "5 messages"
// zh: "5 条消息"
```

### 3. 性别 / 形式

```json
{
  "greeting": "{gender, select, male {先生} female {女士} other {您}}"
}
```

### 4. 数字 / 日期

```typescript
// 不用 i18next,用 Intl API
new Intl.NumberFormat(lang).format(1234.56)
// en: "1,234.56"
// zh: "1,234.56"
// de: "1.234,56"

new Intl.DateTimeFormat(lang).format(new Date())
// en: "8/17/2026"
// zh: "2026/8/17"
```

### 5. RTL 支持(Arabic / Hebrew)

```css
/* 自动适配 */
[dir="rtl"] .icon-arrow-right {
  transform: scaleX(-1);
}

/* 用逻辑属性 */
.container {
  margin-inline-start: 1rem;  /* 不用 margin-left */
  padding-inline-end: 1rem;
}
```

### 6. 字体

```typescript
// 根据 lang 切字体
const fontFamily = {
  'en-US': 'Inter, system-ui',
  'zh-CN': '"PingFang SC", "Microsoft YaHei", sans-serif',
  'ja-JP': '"Hiragino Kaku Gothic ProN", sans-serif',
  'ar-SA': '"Noto Sans Arabic", sans-serif',
}[lang]
```

## 四、提取流程 / Extraction

### 前端

```bash
# 安装 i18next-parser
pnpm add -D i18next-parser

# 提取所有 t('...') 到源文件
pnpm i18n:extract

# 翻译完后验证
pnpm i18n:lint
```

`.i18next-parser.config.js`:

```javascript
module.exports = {
  locales: ['en-US', 'zh-CN', 'zh-TW', 'ja-JP', 'ko-KR'],
  defaultLocale: 'en-US',
  output: 'apps/workbench/src/i18n/locales/$LOCALE.json',
  input: ['apps/workbench/src/**/*.{ts,tsx}'],
  keepRemoved: false,
}
```

### Python

```bash
# 安装 babel
uv add --dev babel

# 提取
pybabel extract src/fnixagent/ -o locales/fnixagent.pot

# 初始化 zh-CN
pybabel init -i locales/fnixagent.pot -d locales/ -l zh-CN

# 编译
pybabel compile -d locales/

# 已有语言更新
pybabel update -i locales/fnixagent.pot -d locales/
```

## 五、翻译流程 / Translation Workflow

### Crowdin / Weblate 集成(可选)

本项目**不**使用第三方翻译平台(因为是专有项目)。翻译工作由项目维护者
直接 PR。

### PR 流程

1. 开发者在代码中加新 key:`t('feature.new_button')`
3. CI 检测到 missing key → 阻塞 PR
4. 翻译者提交翻译 PR
5. 合入后 CI 验证所有 locale 100% 覆盖

### 自动覆盖率检查

`.github/workflows/i18n.yml`:

```yaml
- name: Check i18n coverage
  run: |
    pnpm i18n:check
    # 失败条件:
    # - 任何 locale 覆盖率 < 95%
    # - 主语言(en/zh)缺失关键 key
```

## 六、Locale 切换 / Switching

```typescript
// 自动检测
function detectBrowserLang(): string {
  const stored = localStorage.getItem('fnixagent.lang')
  if (stored) return stored
  const browser = navigator.language
  const supported = ['en-US', 'zh-CN', 'zh-TW', 'ja-JP', 'ko-KR']
  return supported.find(l => browser.startsWith(l.split('-')[0]))
      ?? 'en-US'
}

// 用户切换
await i18n.changeLanguage('zh-CN')
localStorage.setItem('fnixagent.lang', 'zh-CN')
```

## 八、CJK 字数差异

英文与中文文案长度差异显著,UI 必须有充足留白:

```css
/* ❌ 写死 80px,中文会溢出 */
.button { width: 80px; }

/* ✅ min-width + padding */
.button {
  min-width: 60px;
  padding-inline: 12px;
}
```

德文 +30%,阿拉伯文 +25% 都要考虑。
