## 声明概述

本声明适用于 FnixAgent 智能工作台系统 V1.0（以下简称"本软件"）。本软件是一款本地优先（Local-First）的 AI Agent 客户端工作台，采用 BYOK（Bring Your Own Key，用户自带 API Key）架构，软件本身不提供任何 AI 模型服务，仅作为客户端调用用户自行配置的第三方大语言模型（LLM）API 接口，以实现办公任务（Work 模式）与编程辅助（Code 模式）两类应用场景。

本软件的设计理念为：数据本地化、模型服务化、责任用户化。为遵守中华人民共和国相关法律法规及行业监管要求，特制定本 AI 合规声明，明确软件的技术定位、数据处理方式、内容标识规则、用户责任及知识产权归属。

## 一、软件 AI 技术使用说明

### 1.1 技术定位

本软件为 AI Agent 客户端工具，定位为用户与第三方大语言模型服务之间的交互桥梁。本软件自身不包含、不内置、不部署任何自研或第三方的大语言模型，不具备独立的自然语言生成与推理能力。

### 1.2 AI 能力实现方式

本软件的 AI 能力通过调用用户自行配置的第三方 LLM API 实现，所支持的第三方服务包括但不限于：

- OpenAI（GPT 系列）
- Anthropic（Claude 系列）
- 阿里通义千问（Qwen / DashScope）
- 智谱 AI（GLM）
- DeepSeek
- 其他兼容 OpenAI API 协议的第三方模型服务

用户在使用本软件前，须自行前往相应服务商注册账号、获取 API Key，并在本软件的本地配置中完成接入设置。本软件仅在用户主动发起请求时，将用户输入内容经加密通道传输至用户所配置的 LLM API 端点，并接收返回结果呈现给用户。

### 1.3 费用与合规责任

- 用户使用第三方 LLM API 所产生的全部费用，由用户与相应服务商之间独立结算，与本软件无关。
- 用户应确保其所使用的第三方 LLM API 服务已依法取得相关资质或完成备案，用户因使用第三方服务所产生的任何合规责任由用户自行承担。
- 本软件不对任何第三方 LLM API 服务的可用性、准确性、合法性作出担保。

## 二、数据处理与隐私保护

### 2.1 数据存储原则

本软件遵循"数据本地化"原则，用户的全部数据均存储于用户本地文件系统中，不上传至本软件的任何服务器。本地存储的数据包括但不限于：

- 用户与 AI 的对话记录
- AI 辅助生成的工作产物（文档、代码、配置等）
- 用户的偏好设置与会话状态
- 任务执行日志与审计记录

### 2.2 API Key 安全管理

- 用户的 API Key 采用加密方式存储于本地 `~/.fnix` 目录下，不以明文形式持久化保存。
- API Key 仅在本软件发起 LLM API 请求时于内存中解密使用，不写入日志、不上传至任何外部服务。
- 用户可随时在本地配置中删除或轮换 API Key。

### 2.3 数据传输范围

- 本软件不收集、不统计、不上传任何用户身份信息、使用行为数据或设备信息。
- 用户在对话过程中输入的内容，仅传输至用户自行配置的 LLM API 端点，传输过程采用 HTTPS/TLS 加密通道。
- 除用户配置的 LLM API 端点外，本软件不向任何其他第三方服务发送用户对话内容或工作产物。

### 2.4 用户数据控制权

- 用户对其本地存储的全部数据享有完全的控制权，可随时查看、导出、修改或删除。
- 本软件不提供任何形式的远程数据访问接口，不存在云端数据副本。

### 3.1 内容标识机制

本软件通过 AI 辅助生成的文档、代码及其他工作产物，在文件属性（元数据）中标注"由 AI 辅助生成"标识，以明确内容来源。标识信息包括：

- 生成所用的 LLM 服务名称及模型版本
- 生成时间戳
- 生成时所使用的提示词摘要（可选）

### 3.2 用户审查义务

- AI 生成的内容可能存在事实性错误、逻辑偏差或不符合特定场景要求的情况，用户应在正式使用前对内容进行充分审查与核实。
- 用户不得将未经审查的 AI 生成内容直接用于可能对他人权益产生重大影响的场景。
- 用户对 AI 生成内容的最终修改、发布及使用承担全部责任。

### 3.3 法规遵循

本软件的 AI 生成内容标识机制遵循《生成式人工智能服务管理暂行办法》第十二条关于"标识"的相关规定，采取技术措施对 AI 生成内容进行显著标识，便于用户及第三方识别。
