## 五、衍生作品声明

本软件的 `apps/workbench` 前端界面派生自 PunamIDE 项目（MIT 许可证）。原始项目地址：https://github.com/mandaloriantrader/PunamIDE

原始许可证文本保存于 `apps/workbench/LICENSE-MIT-PUNAMIDE` 文件中。

FnixAgent 在 PunamIDE 基础上进行的修改包括：

- 产品标识、提示词、配置键名及数据目录（`.fnix`、`fnix-settings*.json`）

- 工作区初始化机制（`{workspace}/.fnix`）
- 项目规则文件（`.fnix/rules.md` / `AGENTS.md`）
- 移除默认的第三方 Sentry DSN 配置

## 六、清单维护

### 6.1 更新机制

- 本清单将随本软件版本的更新而同步更新，确保与实际依赖保持一致。
- 新增第三方依赖时，开发团队须在提交代码变更的同时更新本清单。
- 依赖版本升级时，须核实新版本的许可证是否发生变更，并相应更新本清单。

### 6.2 许可证审查流程

1. 新增依赖前，开发团队须核实该依赖的许可证类型。
2. 如依赖许可证为 GPL、AGPL 等 copyleft 型许可证，须拒绝引入或寻求替代方案。
3. 如依赖许可证存在专利诉讼条款，须进行法务审查。
4. 许可证审查结果须记录在代码审查（Code Review）流程中。

## 附录：许可证全文获取方式

各第三方依赖的许可证全文可通过以下方式获取：

1. **项目仓库：** 访问各依赖的官方代码仓库（见上表"官方地址"列），查阅仓库根目录下的 `LICENSE` 或 `COPYING` 文件。
2. **包管理器：**
   - Python 依赖：使用 `pip show <package-name>` 查看许可证信息，或访问 https://pypi.org 搜索对应包。
   - npm 依赖：使用 `npm info <package-name> license` 查看许可证信息，或访问 https://www.npmjs.com 搜索对应包。
   - Rust 依赖：使用 `cargo license` 命令或访问 https://crates.io 搜索对应包。
3. **SPDX 许可证列表：** 访问 https://spdx.org/licenses/ 查阅各许可证的标准全文。
