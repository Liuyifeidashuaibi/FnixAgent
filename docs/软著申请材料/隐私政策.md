## 前言

本隐私政策（以下简称"本政策"）旨在向用户（以下简称"您"）说明 FnixAgent 智能工作台系统 V1.0（以下简称"本软件"）在信息收集、数据存储、数据传输及数据安全方面的处理规则。

本软件是一款本地优先（Local-First）的 AI Agent 客户端工作台，采用 BYOK（Bring Your Own Key，用户自带 API Key）架构。**本软件的核心隐私设计原则是：用户数据归用户所有，存储于用户本地，不上传至本软件的任何服务器。**

请您在使用本软件前，仔细阅读并充分理解本政策的全部内容。您下载、安装、访问或以任何方式使用本软件，即视为您已阅读、理解并同意本政策的全部内容。

## 一、信息收集说明

### 1.1 本软件不主动收集用户信息

本软件遵循"最小化数据"原则，**不主动收集、不统计、不上传**任何用户个人信息、使用行为数据或设备信息。具体而言：

- **不收集身份信息：** 本软件不要求用户注册账号，不收集用户的姓名、邮箱、电话、身份证号等个人身份信息。
- **不收集设备信息：** 本软件不上传用户的设备型号、操作系统版本、硬件配置、网络信息、地理位置等设备信息。
- **不收集使用数据：** 本软件不上传用户的使用频率、功能使用情况、点击行为、会话时长等使用行为数据。
- **不收集日志数据：** 本软件不在服务器端记录用户的访问日志、操作日志或错误日志。所有日志均存储于用户本地。
- **不使用追踪技术：** 本软件不使用 Cookie、Web Beacon、设备指纹等追踪技术收集用户信息。

### 1.2 本地存储的信息

以下信息由本软件在用户本地文件系统中创建和存储，不上传至任何外部服务器：

| 信息类别 | 说明 | 存储位置 |
|----------|------|----------|
| 用户配置信息 | 包括界面偏好、语言设置、主题设置等 | `~/.fnix` 目录 |
| API Key | 用户配置的第三方 LLM API 密钥（加密存储） | `~/.fnix` 目录 |
| 对话记录 | 用户与 AI 的对话历史 | `~/.fnix` 目录及工作区 `.fnix` 目录 |
| 工作产物 | AI 辅助生成的文档、代码、配置等 | 用户指定的工作区目录 |
| 任务日志 | 任务执行过程的审计记录与日志 | `~/.fnix` 目录及工作区 `.fnix` 目录 |
| 技能库与记忆 | 用户自定义技能、智能记忆数据 | `~/.fnix` 目录 |

### 1.3 可选的数据导出

- 本软件提供数据导出功能，用户可将其本地存储的对话记录、工作产物等数据导出为标准格式文件。
- 导出的数据由用户自行管理，本软件不对导出数据的安全性承担义务。

## 二、数据存储位置

### 2.1 本地文件系统存储

- 本软件的所有用户数据均存储于用户本地文件系统中，主要存储位置为用户主目录下的 `~/.fnix` 目录及各工作区的 `.fnix` 目录。
- 本软件不维护任何云端数据库或服务器端数据存储，不存在云端数据副本。
- 用户的全部数据始终保留在用户的本地设备上，用户对其享有完全的物理控制权。

### 2.2 三进程架构数据流

本软件采用三进程架构，各进程间的数据流均在本地完成：

- **Tauri Desktop（前端进程）：** 负责用户界面渲染与交互，用户输入数据通过本地进程间通信（IPC）传递。
- **Python agentd（后端代理进程）：** 负责任务编排、LLM API 调用与结果处理，数据在本地内存中流转。
- **fnix-local sidecar（本地辅助进程）：** 负责本地文件系统操作与辅助任务执行。

上述三个进程之间的通信均通过本地回环地址（127.0.0.1）完成，数据不离开用户设备。

### 2.3 数据目录结构

```
~/.fnix/                          # 用户全局数据目录
├── config/                       # 全局配置
├── keys/                         # 加密存储的 API Key
├── skills/                       # 技能库
├── intelligence_memory/          # 智能记忆
├── index/                        # 本地索引
└── logs/                         # 本地日志

{workspace}/.fnix/                # 工作区数据目录
├── artifacts/                    # 工作产物
├── rules.md                      # 项目规则
├── todos.json                    # 待办事项
└── ...                           # 其他工作区数据
```

## 三、API Key 安全存储

### 3.1 加密存储机制

- 用户的 API Key 采用加密方式存储于本地 `~/.fnix/keys/` 目录下，不以明文形式持久化保存。
- 本软件使用 AES-256-GCM 对称加密算法对 API Key 进行加密存储，加密密钥通过本地设备绑定的密钥派生机制生成。
- 密码哈希使用 Argon2id 算法，符合 OWASP 推荐的安全标准。

### 3.2 API Key 使用流程

1. **存储阶段：** 用户输入 API Key 后，本软件立即使用 AES-256-GCM 加密并写入本地文件，明文不驻留内存。
2. **使用阶段：** 本软件仅在发起 LLM API 请求时，于内存中临时解密 API Key 用于请求认证，请求完成后立即从内存中清除。
3. **日志保护：** API Key 不写入任何日志文件，不在错误信息或调试输出中显示。
4. **传输保护：** API Key 仅通过 HTTPS/TLS 加密通道传输至用户配置的 LLM API 端点，不传输至任何其他第三方。

### 3.3 API Key 管理权利

- 用户可随时在本地配置中查看、修改、轮换或删除 API Key。
- 删除 API Key 后，本软件将立即从本地存储中清除对应的加密数据。
- 本软件不保留 API Key 的任何备份或历史版本。

## 四、数据传输说明

### 4.1 传输范围

- 本软件仅在用户主动发起 AI 请求时，将用户输入的对话内容、提示词及相关上下文数据传输至**用户自行配置的 LLM API 端点**。
- 除用户配置的 LLM API 端点外，本软件不向任何其他外部服务发送用户数据。

### 4.2 传输内容

传输至 LLM API 端点的数据可能包括：

- 用户输入的对话文本或指令
- 任务执行所需的上下文信息（如文件内容、代码片段）
- 系统提示词与角色设定
- 会话历史记录（根据用户配置的上下文窗口大小）

### 4.3 传输安全

- 所有至 LLM API 端点的数据传输均采用 HTTPS/TLS 加密通道，确保数据在传输过程中的机密性与完整性。
- 本软件不对传输数据进行任何形式的中间人解密、记录或存储（除本地日志中记录的请求元数据外，如时间戳、模型名称，不含请求内容）。

### 4.4 本地进程间通信

- 本软件三进程架构之间的通信通过本地回环地址（127.0.0.1）完成，数据不经过外部网络。
- 进程间通信采用本地 HTTP 协议，数据在用户设备内部流转，不对外部网络暴露。

- 用户可通过本软件提供的数据导出功能，将其本地数据导出为标准格式文件（如 JSON、Markdown 等）。

### 5.5 卸载与数据清理

- 用户如需彻底清除所有数据，可手动删除上述目录。

## 六、第三方服务说明

### 6.1 第三方 LLM API 服务

- 本软件的 AI 能力通过调用用户自行配置的第三方 LLM API 实现，所支持的第三方服务包括但不限于：
  - OpenAI（GPT 系列）
  - Anthropic（Claude 系列）
  - 阿里通义千问（Qwen / DashScope）
  - 智谱 AI（GLM）
  - DeepSeek
  - 其他兼容 OpenAI API 协议的第三方模型服务

### 6.2 第三方服务隐私政策适用

- 用户在向第三方 LLM API 端点发送数据时，该数据的处理受相应第三方服务商的隐私政策约束。
- **用户应仔细阅读并理解其所使用的第三方 LLM API 服务的隐私政策，了解该服务商如何收集、使用、存储和共享用户数据。**
- 本软件不对第三方服务商的数据处理行为承担责任。第三方服务商对其接收到的用户数据享有独立的控制权。

### 6.3 第三方服务的独立性

- 本软件与第三方 LLM API 服务商之间不存在数据共享、数据传输或商业合作关系。
- 用户与第三方服务商之间的关系独立于本软件，用户应自行遵守第三方服务商的服务条款。
- 用户使用第三方 LLM API 所产生的费用，由用户与相应服务商之间独立结算。

## 七、数据安全措施

### 7.1 加密技术

本软件采用以下加密技术保护用户数据安全：

| 安全措施 | 技术实现 | 适用范围 |
|----------|----------|----------|
| API Key 加密存储 | AES-256-GCM 对称加密 | API Key 本地存储 |
| 密码哈希 | Argon2id | 用户认证（如适用） |
| 数据传输加密 | HTTPS/TLS | 至 LLM API 端点的数据传输 |
| 进程间通信隔离 | 本地回环地址 127.0.0.1 | 三进程间数据通信 |

### 7.2 访问控制

- 本软件不提供远程访问接口，用户数据仅可通过用户本地设备访问。
- 本软件的本地 API 服务默认仅监听 127.0.0.1 地址，不对局域网或公网暴露。

### 7.3 安全审计

- 本软件在本地记录任务执行日志与审计记录，便于用户追溯数据访问与操作行为。
- 审计日志存储于用户本地，不上传至任何外部服务。

### 7.4 安全建议

尽管本软件已采取合理的安全措施，我们仍建议用户采取以下额外安全措施：

- 定期备份本地数据至安全的存储介质；
- 及时更新操作系统与本软件至最新版本；
- 妥善保管 API Key，不在不安全的环境中输入；
- 使用操作系统级别的磁盘加密（如 BitLocker、FileVault）进一步增强数据安全。
