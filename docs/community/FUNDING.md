# 赞助 / Funding

> 由于本项目为专有个人项目,本文件说明资助方式与使用规范。

---

## 一、资助模式 / Funding Models

本项目接受以下形式的支持:

### 1. GitHub Sponsors

- 💖 **个人一次性赞助**:https://github.com/sponsors/fnixagent
- 💖 **月度订阅**:$5 / $10 / $25 / 自定义
- 用途:买咖啡 / 服务器费用 / LLM API 测试

**GitHub 资助流程**:

1. 访问 https://github.com/sponsors/fnixagent
2. 选择金额与频率
3. GitHub Sponsors 处理支付,我们收到 95%(扣 5% 平台费)
4. 每月收到一次转账(PayPal / 银行)

### 2. Open Collective(可选)

适合希望**公开账目**的资助者:

- 透明:所有收支公开
- 发票:可开发票
- 导出:支持 CSV / 会计软件导入

链接:https://opencollective.com/fnixagent(若启用)

### 3. 一次性捐赠

| 渠道 | 备注 |
| --- | --- |
| GitHub Sponsors | 首选 |
| WeChat Pay | 仅限中国大陆,扫码赞助 |

### 4. 实物赞助

部分公司可能希望提供:

- ☁️ 云资源(LLM API 测试额度)
- 🎨 Logo / 视觉设计
- 📚 印刷 / 文具

如有兴趣,请邮件 `liuyifeidashuaibi@gmail.com`。

## 二、资金使用 / Use of Funds

公开账目(每季度):

```
2026 Q3:
  收入:
    GitHub Sponsors:    $120.00
    个人赞助:            $50.00
  支出:
    LLM API 测试:        $42.30 ( / DeepSeek)
    域名 github.com/Liuyifeidashuaibi/FnixAgent:  $12.00
    服务器 (Hetzner):     $7.50
  余额:                  $108.20
```

### 资金优先级

1. **基础设施**(域名、服务器、CI)
2. **测试资源**(LLM API、本地模型 GPU 时间)
3. **设计资源**(Logo / UI 设计,如果用钱更好)
4. **法律 / 合规**(公司注册、商标申请、保险)
5. **应急储备**

**不用于**:
- ❌ 工资 / 个人收入
- ❌ 投资
- ❌ 政治捐款
- ❌ 任何与项目无关的开支

## 六、合规 / Compliance

### 税务

- 收到的赞助在作者所在司法管辖区可能需要申报
- 平台(GitHub / Open Collective)会自动生成税务文件
- 大额赞助($600+ / 年)可能触发 1099 / 银行报告

### 反洗钱

- 不接受现金
- 不接受无法追溯来源的转账
- 保留所有支付凭证 7 年

### 反贿赂

- 不接受"换取代码合入"的资助
- 不接受"换取优先支持"的资助
- 资助者不得要求技术决策变化
