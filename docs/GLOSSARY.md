## 任务图三层 (KTG / STP / MFP) 关系图

```
        ┌────────────────────────────────────────────┐
        │           KTG (Knowledge Task Graph)        │
        │        知识任务图 — 季度到年度              │
        │                                              │
        │  • 战略目标 / 能力领域 / 关键主题             │
        │  • 节点:ktg.NNN                              │
        │  • 边:宏观依赖                               │
        └────────────────────┬─────────────────────────┘
                             │ decompose (LLM)
        ┌────────────────────▼─────────────────────────┐
        │           STP (Short-Term Plan)              │
        │        短期计划 — 天到周                       │
        │                                               │
        │  • 里程碑 / 决策点 / 可交付成果                │
        │  • 节点:stp.<period>.NNN                       │
        │  • 边:中观依赖                                 │
        └────────────────────┬──────────────────────────┘
                             │ schedule (LLM)
        ┌────────────────────▼──────────────────────────┐
        │           MFP (Multi-step Flow Plan)         │
        │        多步流计划 — 秒到分钟                  │
        │                                                │
        │  • 工具调用 / 子 Agent / IO                    │
        │  • 节点:step.NNN                                │
        │  • 边:数据流 / 控制流                           │
        └────────────────────────────────────────────────┘
```

## 常见误用 / Common Misuses

| ❌ 不要说 | ✅ 应该说 |
| --- | --- |
| task list / to-do | STP (短期) 或 MFP (执行) |
| goal / objective | KTG (战略) |
| skill / plugin | Skill (FnixAgent 专有) |
| memory / context | core / episodic / semantic / procedural |
| IDE / Editor | Workbench |
| dashboard / panel | Surface |
