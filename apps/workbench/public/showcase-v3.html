本轮发现并修复的 Bug

一边测试一边发现问题、定位根因、修复并验证 — 三轮迭代

BUG-017 严重
✅ 已修复
Markdown 表格未渲染为 HTML 表格 — Assistant 回复中的 GFM 表格以原始 | 管道符文本显示
根因：MessageBubble.tsx 的 renderContent 使用自定义 Prose 正则解析器，不支持 GFM 表格。
修复：用 MarkdownRenderer（react-markdown + remark-gfm）替换 Prose，移除 renderInline 和 createElement。
验证：TypeScript 零错误 + Plan 模式表格完美渲染 + Ask 模式对比表格验证通过。
BUG-018 中等
✅ 已修复
Mermaid 代码块未渲染为图表 — Plan 模式回复中的架构图显示为原始 graph TB 代码文本
根因：renderContent 将所有代码块统一送入 CodeBlock，未检测 mermaid 语言分流。
修复：添加 lang.toLowerCase() === 'mermaid' 检测，分流到 <MermaidBlock> 组件。
验证：HMR 后 Mermaid 架构图正确渲染（前端/后端/数据库节点可视化）。
BUG-020 中等
✅ 已修复
web_search 工具返回 0 结果 — DuckDuckGo HTML 版返回反爬挑战页（HTTP 202）
根因：html.duckduckgo.com/html/ 返回反爬挑战页，原有正则 result__a 无法匹配。
修复：改用 DuckDuckGo Lite (lite.duckduckgo.com/lite/)，更新解析模式为 rel="nofollow" 链接提取。
验证：直接测试返回 10 条有效结果（React v19、GeeksforGeeks、freeCodeCamp 等）。
BUG-019 低
⚠️ 待确认
会话列表页面重载后为空 — 可能不持久化跨页面重载（需进一步验证是否为设计行为）
观察：页面重载后会话列表仅显示"可恢复任务"，之前的 4 个对话不在列表中。
待确认：是否为内存存储设计，或后端有会话持久化但前端未加载。
