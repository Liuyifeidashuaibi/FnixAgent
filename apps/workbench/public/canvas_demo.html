🎨 FNIX ArtifactCanvas 画布功能演示

对标 Claude Artifacts + OpenAI Canvas — 真正的内联预览与协同编辑体验

📄 多格式支持

支持 HTML、SVG、Markdown、代码文件、图片、文本等多种格式的预览和编辑。

HTML Markdown 代码 图片

👁️ 多视图模式

提供预览、源码、双视图三种模式，HTML 和 Markdown 默认双视图实时同步。

预览 源码 双视图

✏️ 协同编辑

AI patch 增量编辑，Diff 预览确认后落盘，改动行高亮闪烁提示。

增量编辑 Diff 高亮

🔒 安全隔离

HTML 使用 iframe sandbox 隔离，Mermaid 严格模式，显式保存机制。

sandbox CSP XSS防护

📊 Mermaid 渲染

支持 Mermaid 代码块实时渲染，大图自动切换在线渲染避免卡顿。

Mermaid 图表 流程图

🎨 新中式设计

青灰主色、茶白底、思源宋体、细线轴，打造优雅的视觉体验。

宋韵风 极简 优雅
🎯 工作流程 Mermaid · 动态渲染 
```mermaid
graph TD
    A[用户输入] --> B{Think}
    B --> C{Act}
    C --> D{Observe}
    D --> E{Reflect}
    E --> F{Respond}
    F --> B
```
