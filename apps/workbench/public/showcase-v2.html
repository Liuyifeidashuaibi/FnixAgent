Custom Agent Evaluation Harness

Inspired by DeepEval + AgentBench + SWE-bench — built from scratch to test FnixAgent

TraceCollector

  • NDJSON stream parsing from /api/v1/work/stream
  • Captures: mission, thinking, action, observation, text, done, error chunks
  • Extracts: tool_name, tool_args, tool_result, tool_success, safety_block
  • Metrics: step_count, tool_call_count, total_duration, artifacts

ProblemDetector

  • 5-category problem detection (planning / tool_params / rollback / interruption / mcp)
  • Duplicate tool call detection (loop detection)
  • Failed tool call tracking with retry analysis
  • Missing done signal detection (interruption)
  • MCP tool failure detection

EvalRunner

  • 22 test cases across 8 categories (FILE/TOOL/PLAN/ERR/SEC/REL/CODE/GAIA)
  • Checkpoint-based incremental result saving
  • Pass/fail/partial/blocked status determination
  • 0.0-1.0 scoring with bonus/penalty logic

ReportGenerator

  • JSON report (machine-readable, CI integration)
  • Markdown report (human-readable review)
  • HTML report (visual dashboard with charts)
  • Problem distribution matrix by category × severity

Bug Tracking & Fixes

13 bugs discovered through testing and fixed — each verified before closing

BUG-001
z-index conflict + onMouseDown event propagation causing UI click-through
Fix: Added z-index layering and stopPropagation on mouse events
BUG-002
Regex tail suffix matching error in streaming response parser
Fix: Corrected regex pattern (second fix applied after initial fix was incomplete)
BUG-003
Date.now() initialization causing timestamp drift in trace collection
Fix: Used consistent time.time() for all timestamp operations
BUG-004
findLastIndex not available in target ES version
Fix: Replaced with manual reverse loop for broader compatibility
BUG-005
artifact_guardrail path validation too strict, blocking legitimate paths
Fix: Adjusted path validation logic to allow workspace-relative paths
BUG-006
Log deduplication failure causing duplicate entries in execution trace
Fix: Added dedup key based on content hash + timestamp window
BUG-007
API key masking confirmation dialog not displaying correctly
Fix: Fixed mask display logic and confirmation flow
BUG-010
home_dir field not populated in sidecar configuration
Fix: Added home_dir resolution from system env
BUG-011
sendDisabled state not properly synced with streaming status
Fix: Added state synchronization on stream start/end events
BUG-012
overflow:hidden clipping artifact content in canvas view
Fix: Changed to overflow:auto with proper scroll container (second fix)
BUG-013
SHELL tool blocking on auto_approve_high standalone commands
Fix: Added standalone approval path for high-risk shell commands
BUG-014
Heartbeat message concatenation instead of replacement causing UI spam
Fix: Changed from append to replace for heartbeat messages
BUG-015
Thinking block heartbeat "仍在思考中...(Step N)" not cleared after task completion
Fix: finalize function now replaces heartbeat with "分析完成" message
