## Adding yourself

If you are added as a maintainer:

1. Add your entry in the **Active Maintainers** table with avatar, GitHub handle, scope, and a contact channel.
2. Update [GOVERNANCE.md](GOVERNANCE.md) if your role changes the decision process.
3. Get added to the appropriate teams in the GitHub org (`@fnixagent/maintainers`, `@fnixagent/security`).
4. Sign the **Maintainer Agreement** below.

### Maintainer Agreement (informal)

> _"I will use my write access in the best interest of the FnixAgent project and its users, follow the [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), respect the [GOVERNANCE.md](GOVERNANCE.md) decision process, and step down gracefully if I can no longer fulfill the role."_
