[html:l610] 6. 问题清单与修复建议
[html:l614] P0-01: BYOK API Key 配置源断裂 — Work/Chat 流式功能完全不可用
[html:l615] P0
[html:l618] 前端设置面板存储的加密 API Key 未被后端
[html:l619] llm_policy.py:resolve_api_key() 读取。后端只检查
[html:l620] os.getenv() 环境变量，而 .env 中 Key 值已清空。
[html:l623] 复现：
[html:l624] curl -X POST /api/v1/work/stream -d '{"user_input":"hello"}' -H "Authorization: Bearer
[html:l625] $TOKEN"
[html:l626] → {"chunk_type":"error","content":"请先在 Desktop 设置中填写您自己的 API Key（Fnix 仅支持
[html:l627] BYOK）"}
[html:l630] 修复方向： 在 llm_policy.py:resolve_api_key() 中增加从
[html:l631] harness 加密存储读取 Key 的回退路径，或在前端发送 work/stream 请求时附带请求级
[html:l632] llm.api_key （从 localStorage 解密后传入）。
[html:l638] P0-02: 会话恢复失败 — "cannot rebuild messages from events"
[html:l639] P0
[html:l642] 点击已有会话时，后端无法从事件存储重建消息列表，导致历史会话不可查看。
[html:l645] 复现： 在侧栏点击任意已有会话 → 页面显示
[html:l646] {"detail":"cannot rebuild messages from events"}
[html:l649] 修复方向： 检查 harness/session.py 中的
[html:l650] rebuild_messages_from_events() 函数，可能事件序列化格式变更后未做向后兼容。
[html:l656] P0-03: /api/v1/coding/status 返回 404

[html:l663] 修复方向： 在 api/routers/ 中注册 coding
[html:l664] 路由，或确认前端是否使用了不同的端点路径。
