HTML - HyperText Markup Language

HTML is the standard markup language used to create and structure content on web pages. It defines the meaning and structure of web content using a system of tags and attributes.

Basic Structure

Every HTML document follows a basic structure:

<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>Heading</h1>
    <p>Paragraph content</p>
  </body>
</html>

Common HTML Elements

  • <div> - Block-level container for grouping elements
  • <span> - Inline container for text styling
  • <a> - Hyperlinks to other pages or resources
  • <img> - Embed images into the page
  • <form> - Create interactive forms for user input
  • <table> - Display tabular data in rows and columns
  • <header> - Defines the header section of a page
  • <footer> - Defines the footer section of a page

Semantic HTML5

HTML5 introduced semantic elements that clearly describe their meaning to both the browser and the developer. These include <article>, <section>, <nav>, <aside>, and <main>. Using semantic HTML improves accessibility, SEO, and code readability.

Attributes

HTML elements can have attributes that provide additional information. Common attributes include id, class, style, title, and data-* for custom data storage.
