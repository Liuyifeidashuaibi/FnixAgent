# Bruno

A lightweight, open-source API client built for developers.

## Features
- Beautiful UI with dark/light mode
- Collection and request organization
- Environment variables support
- Request scripting with JavaScript
- Response preview and formatting

## Getting Started

### Installation

Download the latest release from [GitHub Releases](https://github.com/usebruno/bruno/releases)

### Development

```bash
# Clone the repository
git clone https://github.com/usebruno/bruno.git

cd bruno

# Install dependencies
npm install

# Start development server
npm run dev
```
