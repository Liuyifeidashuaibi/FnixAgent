# Clear Cache Button

A simple UI component for clearing cached data from the error recovery screen.

## Usage

```jsx
<ClearCacheButton onClear={handleClearCache} />
```

## Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `onClear` | Function | Yes | Callback function triggered when button is clicked |

## Accessibility

- Includes proper title attribute for screen readers
- Uses semantic HTML button element
- Follows Bruno's styling conventions
