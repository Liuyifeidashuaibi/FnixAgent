# Contributing to Bruno Selection List

Thank you for considering contributing to the Bruno Selection List component!

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature-name`
3. **Commit your changes**: `git commit -m 'feat: add your feature'`
4. **Push to your fork**: `git push origin feature/your-feature-name`
5. **Open a Pull Request**

## Code Style

- Follow Bruno's coding standards
- Use TypeScript with strict typing
- Ensure accessibility compliance (ARIA attributes, keyboard navigation)
- Support both light and dark modes
- Write unit tests for new functionality

## Testing

Run tests with:

```bash
npm test
```

## Storybook

Preview components in Storybook:

```bash
npm run storybook
```

## Documentation

- Update README.md with usage examples
- Document new props in SelectionList.README.md
- Add stories for new features
