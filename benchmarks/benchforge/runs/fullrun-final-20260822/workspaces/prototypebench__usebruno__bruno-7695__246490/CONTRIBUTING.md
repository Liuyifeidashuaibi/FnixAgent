# Contributing to Bruno Scroll Persistence

Thank you for considering contributing to Bruno Scroll Persistence! We appreciate your time and effort.

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/your-feature-name`)
3. **Commit your changes** (`git commit -m 'Add some feature'`)
4. **Push to the branch** (`git push origin feature/your-feature-name`)
5. **Open a pull request**

## Code Style

- Follow TypeScript best practices
- Use descriptive variable names
- Include JSDoc comments for exported functions and hooks
- Write tests for new functionality
- Keep PRs focused on a single issue or feature

## Testing

We use Jest for testing. To run tests:

```bash
npm test
```

## Pull Request Guidelines

- Please ensure your PR addresses only one issue or adds one feature
- Include appropriate tests
- Update documentation if necessary
- Follow the [contribution checklist](https://github.com/usebruno/bruno/blob/main/contributing.md)
