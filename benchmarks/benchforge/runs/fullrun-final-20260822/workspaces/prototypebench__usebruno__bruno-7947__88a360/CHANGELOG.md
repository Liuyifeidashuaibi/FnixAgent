# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-22

### Added

- Scroll position persistence for request editor panes (Headers, Assertions, Body)
- `useScrollPosition` React hook for easy integration
- Comprehensive unit tests for scroll position management
- TypeScript type definitions
- Configuration options for scroll position behavior
- Documentation and examples

### Fixed

- No breaking changes introduced
- Error handling for localStorage failures

### Performance

- Optimized scroll event handling with debouncing
- Memory-efficient caching strategy

## [0.1.0] - 2026-08-22

### Added

- Initial implementation of scroll position manager
- Basic React component integration examples
- Test infrastructure setup
