# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-22

### Added
- Example index storage in snapshots (BRU-3385)
- `__exampleIndex` property preservation during snapshot creation
- Utility functions for getting and updating examples by index
- Comprehensive test coverage for example index functionality

### Changed
- Updated snapshot utility to handle example indices
- Enhanced collection utilities to integrate with snapshot system

### Fixed
- Improved reliability of snapshot/restore operations for collections with examples

### Documentation
- Added README documentation for example index functionality
- Updated type declarations for new utilities
