CSS - Cascading Style Sheets

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML. CSS describes how elements should be rendered on screen, on paper, in speech, or on other media.

CSS was first proposed by Håkon Wium Lie in 1994 and has since evolved through multiple levels. CSS3 introduced powerful features like flexbox, grid layout, animations, and media queries for responsive design.

Important concepts in CSS include:

  • The Box Model (margin, border, padding, content)
  • Selectors and specificity
  • Flexbox and Grid layout systems
  • Responsive design with media queries
  • CSS custom properties (variables)
  • Transitions and animations

CSS preprocessors like Sass and LESS extend CSS with features such as variables, nesting, and mixins to make stylesheet authoring more efficient.
