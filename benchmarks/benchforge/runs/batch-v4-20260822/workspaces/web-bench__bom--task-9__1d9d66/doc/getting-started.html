Introduction

This is a sample documentation page demonstrating the theme switching functionality. The theme selector in the top-right corner allows you to toggle between dark and light modes.

Features

The theme preference is automatically saved to localStorage, so your choice persists across page visits and is synchronized across all documentation pages.

Try changing the theme using the selector above - you'll notice the change applies instantly and will be remembered when you navigate to other pages.
